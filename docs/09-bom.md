## 3. Расходники

- Li-Po bag, негорючая подложка.
- Термопаста/теплопроводящий скотч для TP4056 (опция).
- Спиртовые салфетки, щётка для плат.
- Маркеры/бирки для проводов.
- Запасные FPC-шлейфы для EPD (если есть).

## 4. Что не покупать пока

| Позиция | Почему |
|---|---|
| Второй экран IPS 240×320 | Сначала решение по форм-фактору (B4). |
| LRA + DRV2605 | Дороже и крупнее; только если ERM не устроит. |
| MAX17048 | Пока хватает ADC; купить, если точность важна. |
| BQ24075/MCP73871 | Если TP4056 + load-sharing устроит. |
| Дорогой ЦАП ES9038 | Избыточно для IEM и этого бюджета. |
| Готовый корпус | Сначала макет и габариты. |

## 5. Закупочные заметки

- **ESP32:** покупайте у продавца с описанием «N16R8, 16MB, 8MB PSRAM, USB-C» и фото
  шелкографии. После получения — `esptool flash_id`.
- **PCM5102A:** клоны могут иметь неверные перемычки; проверьте `XSMT` и `SCK`.
- **TP4056:** некоторые платы без DW01A; смотрите маркировку.
- **Li-Po:** только с защитой; проверьте полярность JST (красный +, чёрный −).
- **microSD:** 64 ГБ — форматировать FAT32 (Rufus/SDCardFormatter), не exFAT.
- **Медная лента:** проводящий клей лучше; пайка к ленте — с флюсом и коротким нагревом.
- **PETG для корпуса:** PLA деформируется в тёплом корпусе/на солнце.
