## Правила ведения

- **Любое изменение железа** сначала попадает в `02-pinout.md` и ADR, потом в код.
- **Любая ошибка** (сборки, прошивки, монтажа) фиксируется в `06-devlog.md`:
  симптом → причина → исправление → вывод.
- **Любой тест** получает ID в `05-test-plan.md`; результат — `PASS/FAIL/BLOCKED` с датой.
- **Любое архитектурное решение** — ADR в `docs/adr/`, ссылка в `10-decisions.md`.
- Не удаляйте историю: ошибочные решения полезны, если описаны честно.
