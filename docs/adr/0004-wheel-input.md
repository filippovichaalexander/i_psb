# ADR-0004: Колесо — TTP229 + декодер переходов

- **Статус:** Accepted
- **Дата:** 2026-11-24
- **Контекст:** TTP229 — 2-wire (не I2C), 16 бит, active-low, отклик ~32 мс,
  автокалибровка (~4 с по сообщениям). Удержание пальца может «исчезать».
  ESP32-S3 имеет 14 touch-каналов, но все заняты (SPI/I2S/кнопки).
- **Решение:**
  - Оставить TTP229 в M0; читать маску каждые 10 мс.
  - `WheelDecoder` реагирует на переходы секторов, а не на абсолютное касание;
    игнорирует прыжки >3; сбрасывается после 150 мс без касания.
  - MPR121/CAP1203 — план B, если шум/калибровка не устроят.
- **Последствия:** устойчиво к autocal, но 32 мс — предел; быстрый скролл может
  терять тики.
- **Альтернативы:** native touch (не хватает пинов); AS5600 (нужен вращающийся магнит).
