# ADR-0002: E-Ink UI и политика обновления

- **Статус:** Accepted (выбор экрана остаётся открытым)
- **Дата:** 2026-11-24
- **Контекст:** WeAct 2.13" 250×122, 2:1 landscape, partial refresh ~0.3 с,
  ghosting. iPod classic — 4:3 portrait. Анимация и прогресс 1 Гц невозможны.
- **Решение:**
  - UI страничный: full refresh при смене экрана, partial — только область списка/
    статуса, full каждые 20–30 partial.
  - Coalesce wheel 150–200 мс; min interval 250 мс.
  - Прогресс — раз в 10–15 с.
  - Шрифты: Unifont/Courier Cyrillic в M0; кастомный — M2.
- **Последствия:** UI выглядит «медленным», но предсказуемым; ghosting контролируем.
- **Альтернативы:** IPS 240×320 (быстрый, цвет, подсветка); Sharp Memory LCD
  (быстрый, дорого). Решение за владельцем после макета.
