# ADR-0003: Перенос ADC батареи на GPIO10

- **Статус:** Accepted
- **Дата:** 2026-11-24
- **Контекст:** В ТЗ `BAT_ADC = GPIO42`. ESP32-S3 имеет ADC только на GPIO1–20
  (ADC1 1–10, ADC2 11–20); GPIO42 — обычный GPIO. ADC2 конфликтует с Wi-Fi.
- **Решение:** `BAT_ADC = GPIO10` (ADC1_CH9), `EPD_CS = GPIO21`.
  Делитель 100K/100K + 100 нФ; 32 замера; EMA; кривая Li-Po.
- **Последствия:** батарея измеряется; EPD CS — программный, работает.
- **Альтернативы:** GPIO3 (strapping — нет); MAX17048 fuel gauge (апгрейд);
  внешний I2C ADC (лишние пины).
