# ADR-0001: Аудио-стек v0 — Arduino + ESP32-audioI2S

- **Статус:** Accepted
- **Дата:** 2026-11-24
- **Контекст:** Нужен рабочий локальный плеер быстро. `ESP32-audioI2S` даёт
  MP3/AAC/WAV/FLAC/OGG и HTTP-потоки, но документирует 16–48 кГц и имеет
  ограничения на hi-res FLAC. Свой декодер + I2S ring — месяцы работы.
- **Решение:** для v0 использовать `ESP32-audioI2S` (16/44.1–48), спрятать за
  интерфейсом `IAudioBackend`. 24/96 — отдельный тракт в v1, если измерения
  подтвердят realtime.
- **Последствия:**
  - Быстрый M2, меньше риска.
  - README не должен обещать 24/96.
  - I2S DMA — internal RAM; декодированный буфер — PSRAM.
  - Нужен счётчик underrun и soak-тест.
- **Альтернативы:** `dr_flac` + свой I2S; ESP-ADF; libFLAC. Отложены до M2+.
