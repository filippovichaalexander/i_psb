# ADR-0007: USB data path для прошивки и логов

- **Статус:** Proposed (требуется решение владельца)
- **Дата:** 2026-11-24
- **Контекст:** TP4056 Type-C — только зарядка. ESP32-S3 USB на GPIO19/20.
  Без данных нельзя прошить/увидеть логи/восстановить устройство.
- **Варианты:**
  1. Второй USB-C (данные) — просто, но два выреза.
  2. Один Type-C с разведёнными D+/D− — красиво, но зависит от платы TP4056.
  3. Pogo/4-pin header внутри — дёшево, но корпус открывать.
  4. Только OTA — рискованно для первого прототипа.
- **Решение (предложение):** на прототипе — вариант 1 или 3; в финале — OTA +
  скрытые pogo. BOOT/RST — обязательно.
- **Последствия:** нужно место в корпусе и аккуратная разводка VBUS/D+/D−/GND.
