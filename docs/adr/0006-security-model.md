# ADR-0006: Модель безопасности

- **Статус:** Accepted (частично, M3+)
- **Дата:** 2026-11-24
- **Контекст:** Устройство поднимает AP, HTTP и BLE; в ТЗ пароль AP `12345678`,
  веб без auth, OTA нет. Это недопустимо для устройства с файлами и прошивкой.
- **Решение:**
  - Уникальный WPA2-пароль на устройство, генерируется при первом boot,
    показывается на EPD; сброс — кнопкой.
  - HTTP: токен в заголовке для destructive; whitelist путей; лимит размера.
  - BLE: bonding/passkey; отключаемо; не отдавать файлы.
  - OTA: пароль + подпись; rollback через otadata.
  - Секреты — в NVS/`/config`, не в git.
- **Последствия:** первичная настройка сложнее, но устройство не «открытый диск».
- **Альтернативы:** secure boot (сложно/дорого для DIY); open AP (нет).
