# Ввод железа в эксплуатацию: инструменты, порядок, критерии

> **Главное правило:** сначала макет на столе, потом корпус. Не паяйте всё сразу.
> После каждого шага — измерение и запись в `06-devlog.md`.
> Если что-то греется, пахнет или дымит — сразу отключайте питание, не «подождите ещё».

## 1. Безопасность

- Li-Po: не прокалывать, не сгибать, не паять напрямую к банке без лепестков.
  Заряжать на негорючей поверхности, в Li-Po bag, под присмотром.
- Блок питания на первом включении — **с ограничением тока** (200–300 мА).
- Очки при пайке/кусачках; вытяжка или открытое окно; не вдыхать флюс.
- ESD: браслет или хотя бы касание заземлённого корпуса перед платой.
- Не подключать USB и батарею одновременно, пока не проверена цепь питания.
- Не оставлять заряженное устройство без присмотра в закрытом корпусе.

## 2. Инструменты (минимум → комфорт)

| Инструмент | Минимум | Комфорт | Зачем |

## 3. Расходники

- МГТФ 0.07 мм² (или 30 AWG silicone wire) — сигналы; 2 жилы в параллель — питание.
- Медная лента 20 мм с проводящим клеем (или обычная + пайка).
- Каптоновый скотч, малярный скотч, термоусадка 1.5–3 мм.
- Разъёмы JST-PH 2.0 (батарея), dupont, pogo-pin 4 pin.
- Резисторы 0805: 2K/3K/4K (Rprog), 10K (gate), 100K ×2 (делитель), 22Ω (series output, опция).
- Конденсаторы 0805: 100 нФ ×5, 10 мкФ ×2, 22 мкФ ×2.
- Диод 1N5819, MOSFET 2N7002.
- Нейлоновые винты M2.5×6, латунные вставки M2.5 (для PETG).
- Изоляция: каптон на низ плат, термоклей для strain relief (аккуратно).

## 4. Стенд

```text
БП 3.8 В (limit 200 мА) ──► TP4056 B+/B− (или напрямую на OUT+)
                                  │
                                  ├── 3.3V buck ──► ESP32/EPD/SD/TTP
                                  ├── PCM5102 VIN ──► I2S
                                  └── MAX97220 VCC ──► OUT → 32Ω dummy / IEM
Мультиметр: ток последовательно, напряжение на точках
Осциллограф: BCK/LRCK/DIN, ripple 3.3V, выход AMP
```

**Правило:** сначала питание, потом MCU, потом периферия. Не включайте всё сразу.

## 5. Пошаговый ввод

### Шаг 0. Идентификация платы (до закупки остального)

**Что сделать:**

1. Сфотографировать плату с двух сторон, шелкографию, разъёмы.
2. Найти точное название/ссылку товара, скачать pinout/схему.
3. Подтвердить: N16R8 (16 МБ flash, 8 МБ Octal PSRAM), USB-C/D+/D−, наличие GPIO38–42, 47–48.
4. Прошить `esptool.py flash_id` и `chip_id`.

**Критерий:** плата соответствует ТЗ по GPIO и USB. Если нет — **стоп**, пересобрать pinout.

**Команды:**

```bash
esptool.py --port /dev/ttyACM0 chip_id
esptool.py --port /dev/ttyACM0 flash_id
```

### Шаг 1. Питание без ESP32

1. Собрать TP4056 + buck-boost, без нагрузки.
2. Подать 3.8 В на B+/B− (или заряженную батарею).
3. Измерить `OUT+`, `3.3V_DIG`, ток холостого хода.
4. Проверить полярность и отсутствие КЗ между 3.3V и GND.

**Критерий:** 3.30 ±0.05 В, ripple <30 мВ, ток <10 мА без нагрузки.
**Стоп:** нагрев, запах, напряжение >3.6 В на 3.3V-шине.

### Шаг 2. ESP32: прошивка и логи

1. Подключить USB **данных** (не TP4056!) к ПК.
2. Прошить тест: `pio run -t upload`; открыть `pio device monitor`.
3. Проверить: `ESP.getFlashChipSize()` = 16 МБ, `psramFound()` = true, heap/PSRAM.
4. Проверить reset reason, MAC, USB CDC.

**Критерий:** стабильный serial, PSRAM 8 МБ, flash 16 МБ.
**Если нет serial:** проверить, что `ARDUINO_USB_CDC_ON_BOOT=1`, драйвер, кабель (data, не charge-only).

### Шаг 3. E-Ink

1. Подключить по таблице: 3.3V, GND, MOSI 11, SCK 12, CS 21, DC 13, RST 14, BUSY 15.
2. Прошить тест GxEPD2 (boot screen).
3. Проверить full refresh, затем partial.
4. Если белый/мусор — проверить BUSY, RST, 3.3V, правильный класс `GxEPD2_213_B74`.

**Критерий:** читаемый текст, без полос; partial <0.5 с.
**Стоп:** экран горячий, запах — отключить.

### Шаг 4. microSD

1. Карта 64 ГБ, FAT32, кластер 32 КБ (не exFAT).
2. Подключить HSPI: MOSI 7, MISO 8, SCK 6, CS 9; 3.3V.
3. Прошить тест: mount, список, запись/чтение файла.
4. Создать `/Music`, положить 3 файла, включая кириллическое имя.

**Критерий:** mount <1 с, список 100 файлов <2 с, кириллица читается.
**Если fail:** проверить 3.3V, CS, формат, другую карту.

### Шаг 5. Кнопки и колесо

1. Кнопки: проверить замыкание на GND, `INPUT_PULLUP`, debounce 20 мс.
2. TTP229: питание 3.3V, SCL 4, SDO 5, `INPUT_PULLUP`.
3. Прошить тест: вывести маску 16 бит, номер сектора, delta.
4. Нанести 8 секторов медной лентой; проверить переходы по часовой/против.
5. Проверить удержание 5 с (автокалибровка) и быстрое вращение.
6. Вибро: 15 мс импульс, диод катодом к +, MOSFET gate 10K на GND.

**Критерий:** один сектор = один тик; нет дребезга; удержание не «залипает».
**Если TTP шумит:** экран/SPI рядом, длинные провода, плохой контакт меди; попробовать MPR121.

### Шаг 6. Батарея (ADC)

1. Делитель 100K/100K от `OUT+` к GND, средняя точка → GPIO10, 100 нФ на GND.
2. Сравнить `analogReadMilliVolts(10) * 2` с мультиметром на `OUT+` в 3 точках.
3. Записать отклонение; при необходимости — калибровочный коэффициент в NVS.
4. Проверить кривую разряда: 4.18, 3.9, 3.7, 3.5, 3.3 В.

**Критерий:** ±0.05 В, проценты монотонны.
**Не** использовать GPIO42: там нет ADC.

### Шаг 7. DAC и усилитель (осторожно!)

1. PCM5102: выпаять джек, перемычки `1,2,3` → L, `4` → H, `SCK` → GND.
2. Подключить I2S: DIN 17, BCK 18, LCK 16; VIN от `OUT+`, GND к звезде.
3. MAX97220: VCC от `OUT+`, 22 мкФ + 100 нФ; входы L/R от PCM; выходы на PJ320.
4. Первый тест — **32Ω dummy load**, не наушники. Синус 1 кГц, громкость 4/21.
5. Осциллограф: BCK/LRCK/DIN, выход AMP; проверить клиппинг, DC offset, шум.
6. Только потом — дешёвые наушники на минимальной громкости, затем IEM.

**Критерий:** чистый синус, нет клиппинга на 4/21, нет щелчка при старте.
**Стоп:** нагрев MAX97220, постоянка на выходе >50 мВ, громкий щелчок.

**XSMT:** если есть свободный GPIO (47/48), управлять им; иначе RC-задержка.
**MCLK:** опционально GPIO47/48 → SCK PCM; убрать перемычку SCK–GND.

### Шаг 8. RF и антенна

1. BLE advertising: измерить RSSI на 1/5/10 м (nRF Connect).
2. Wi-Fi AP: подключиться телефоном, проверить IP.
3. Повторить с батареей, медной лентой и экраном на месте.
4. Если RSSI упал >10 дБ — перекомпоновать, поднять ESP32 на край, убрать медь.

**Критерий:** −60 дБм на 1 м, −75 дБм на 5 м (ориентир).
**Стоп:** RSSI < −85 дБм на 1 м — антенна задавлена.

### Шаг 9. Зарядка и тепло

1. Rprog 3–4 кОм → 300–400 мА.
2. Заряд 30 мин: ток, напряжение, температура TP4056 и батареи.
3. Проверить, работает ли заряд при выключенном плеере (после переноса switch).
4. Проверить load-sharing или запрет воспроизведения при заряде.

**Критерий:** TP4056 <60 °C, батарея <40 °C, ток стабилен.
**Стоп:** TP4056 >70 °C, батарея вздулась — немедленно отключить.

### Шаг 10. Сборка

1. Каптон на низ всех плат; проверить, что ничего не коротит.
2. Strain relief на проводах; батарея на двусторонний скотч, не на клей поверх.
3. Антенное окно без меди/батареи; PETG, не PLA (температура).
4. Латунные вставки M2.5; винты не вкручивать в пластик напрямую.
5. Собрать, проверить кнопки/колесо/джек/USB/switch до закрытия.

## 6. Типовые неисправности

| Симптом | Вероятная причина | Что проверить |
|---|---|---|
| Нет serial | charge-only кабель, CDC off, драйвер | Кабель, `ARDUINO_USB_CDC_ON_BOOT`, порт |
| Boot loop | brownout, 3.3V просадка, PSRAM mode | 3.3V, ток, `qio_opi`, питание USB |
| SD не монтируется | 3.3V, CS, exFAT, плохой контакт | Формат, пайка, другая карта |
| EPD мусор | BUSY/RST, класс панели, 3.3V | Пины, `GxEPD2_213_B74`, питание |
| Нет звука | XSMT, SCK-GND, I2S пины, MCLK | Перемычки, осциллограф, `setPinout` |
| Щелчки | XSMT, порядок питания, зарядка | RC/GPIO, mute, USB |
| TTP «залипает» | автокалибровка, шум, медь | Переходы, экран, MPR121 |
| BLE далеко | антенна, медь, батарея | Keep-out, RSSI |
| TP4056 горячий | 0.58 А, плохой полигон | Rprog, вентиляция, ток |
| Батарея врёт | GPIO42, делитель, нагрузка | GPIO10, 100 нФ, калибровка |

## 7. Что прислать мне для диагностики

- Фото платы с двух сторон и ссылку на товар.
- `esptool flash_id`, `chip_id`.
- Полный serial log с момента reset (не хвост).
- Напряжения: `OUT+`, `3.3V_DIG`, `BAT_ADC`, `VCC` PCM/MAX.
- Осциллограммы BCK/LRCK/DIN и выхода AMP (если есть).
- Что уже проверено и что исключено.
- Версию прошивки/коммит.

## 8. Чек-лист приёмки M1

- [ ] Плата идентифицирована, GPIO/USB подтверждены.
- [ ] 3.3 В стабильны, ripple <30 мВ.
- [ ] ESP32 прошивается, PSRAM 8 МБ, serial стабилен.
- [ ] EPD full/partial, без артефактов.
- [ ] SD 64 ГБ, кириллица, 100+ файлов.
- [ ] 5 кнопок + 8 секторов + вибро.
- [ ] ADC ±0.05 В, кривая монотонна.
- [ ] Звук: синус, без клиппинга/щелчков, старт 4/21.
- [ ] BLE RSSI в норме с батареей и медью.
- [ ] TP4056 <60 °C, батарея <40 °C.
- [ ] Всё записано в devlog.
