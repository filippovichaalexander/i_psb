# CAD scaffold

`case.scad` — параметрический **каркас**, не финальная модель. Он задаёт габариты,
окно экрана, вырез колеса, боковые вырезы, стойки и keep-out антенны. Печатать
только после M1 bring-up и подтверждения платы.

## Рендер

```bash
# обе части (для просмотра)
openscad -o ../build/case.stl case.scad

# только перед
openscad -D 'part="front"' -o ../build/case_front.stl case.scad

# только зад
openscad -D 'part="back"' -o ../build/case_back.stl case.scad

# без прозрачных компонентов
openscad -D 'show_components=false' -o ../build/case.stl case.scad
```

Через Docker:

```bash
docker run --rm -v "$PWD/..":/workspace -w /workspace/cad \
  openscad/openscad:latest openscad -o /workspace/build/case.stl case.scad
```

## Параметры

| Параметр | Значение | Менять когда |
|---|---:|---|
| `case_w` | 80 | после компоновки |
| `case_h` | 76 | после компоновки |
| `case_d` | 18 | после выбора экрана/батареи |
| `wall` | 2.0 | 2.0–2.4 |
| `screen_w/h` | 50.6 / 25.7 | по факту окна |
| `wheel_d` | 40 | по факту колеса |
| `part` | both | front/back для печати |

## Печать

- PETG, 0.2 мм, 3 периметра, 20–30% infill.
- Ориентация: передняя панель лицом вниз (окно — мост, поддержки аккуратно);
  задняя — задней стенкой вниз.
- Латунные вставки M2.5 — термоусадкой, не молотком.
- Примерка без электроники, затем с электроникой, потом финал.

## Важно

- **Антенна:** верхний правый угол — keep-out ≥15 мм, без меди, батареи, экрана.
- **Колесо:** медь на внутренней стороне, пластик 0.8–1.2 мм, без воздушного зазора.
- **TP4056:** вентиляционные отверстия, не закрывать теплоизоляцией.
- **USB:** два выреза (заряд + данные) или pogo; решение — ADR-0007.
- **Экран:** 2.13" 2:1 landscape; если перейдёте на IPS 240×320, пересчитать всё.
