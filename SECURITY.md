# Security Policy

## Поддерживаемые версии

Проект находится в стадии M0 (blueprint). Исправления безопасности применяются к `main`
и `develop`.

## Как сообщить

Не открывайте публичный issue для уязвимости. Напишите владельцу репозитория через
GitHub Security Advisory (вкладка **Security → Report a vulnerability**) или приватно.

## Что считается уязвимостью

- Обход аутентификации веб-интерфейса или BLE.
- Path traversal в файловом API.
- Выполнение кода через загрузку файлов/обновление прошивки.
- Утечка паролей Wi-Fi/BLE из `/config`.
- Небезопасные дефолты (например, фиксированный пароль AP).

## Известные ограничения M0

- Веб-интерфейс работает с mock-API; прошивка ещё не поднимает HTTP-сервер.
- BLE не реализован.
- Пароль AP `12345678` из исходного ТЗ запрещён к использованию; см. `docs/13-security.md`.
- OTA отсутствует; прошивка пока заливается по USB.

## Секреты

Никогда не коммитьте:

- `firmware/include/secrets.h`
- `.env`, `*.pem`, `*.key`
- реальные `wifi.json` / `stations.json` с паролями

В репозитории допустимы только примеры (`*.example`).
